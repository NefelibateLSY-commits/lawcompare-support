获取支持

iPhone 与 iPad 版：打开应用，进入“我的 → 设置 → 向作者反馈”。Mac 版：打开应用，进入“帮助与反馈”。当前版本会把反馈直接提交到作者的服务器并转发到作者邮箱，无需自行打开邮件应用；较早版本可能调用系统邮件应用。

涉及个人信息、交易凭据、账户或设备登记等不宜公开的问题，请使用应用内“向作者反馈”，或发送邮件至 minfazhixing@163.com；不要通过公开页面提交隐私请求。

也可以通过公开支持页面提交请求：提交支持请求（需要 GitHub 账号）。该页面为公开讨论，请勿提交笔记全文、身份信息、密码、交易凭据或其他私人资料；描述问题时可使用去除个人信息的示例。

为便于定位问题，请说明设备类型（Mac / iPhone / iPad）、系统版本、应用版本、法库版本、问题表现和复现步骤。请勿在反馈中附加完整笔记或数据库文件。

功能与更新

中国大陆、香港特别行政区、澳门特别行政区及台湾地区法库和个人笔记功能免费；域外译文数据库通过 App Store 年度订阅访问。订阅、试用资格、扣费、退款与取消由 Apple 处理，可在应用内恢复购买，或在 Apple 账户的订阅设置中管理。

应用功能更新通过 App Store 分发。法库数据更新与应用版本相互独立：可在应用内“应用更新”和“法库更新”分别检查和安装；某些法库版本可能要求先更新应用。iPhone 与 iPad 版可按设置仅在 Wi-Fi 下自动下载法库更新。

付费域外正文采用在线订阅核验与加密内容服务。打开付费域外正文时，应用会取得短时阅读授权（新版客户端按一部法律授权，不超过 30 分钟，在授权有效期内可连续阅读该部法律；较早版本可能按条文分别核验）；授权到期或应用返回前台后可能需要重新验证，付费正文不支持离线阅读。

本机内容与 iCloud

笔记、收藏、书签、高亮和阅读记录默认保存在本机。Mac 版可在应用中主动开启 iCloud 同步；iPhone 与 iPad 版在登录 iCloud 并允许本应用使用 iCloud 时，会通过 Apple 的 iCloud 键值存储在你自己账户内同步阅读与笔记记录。开发者不运营保存这些内容的服务器，也无法读取你的笔记。当前版本不提供应用内账户或“通过 Apple 登录”入口。具体范围、删除和账户变化的影响见隐私政策。

同一 Apple 订阅最多支持 3 台设备同时阅读域外译文；该并发策略适用于后续支持阅读心跳的新版客户端且服务器策略启用后，当前兼容模式尚未启用。不限制累计登记设备数，可自由更换设备。设备登记仅用于查看和移除，电脑、iPad、iPhone 类别仅作显示；移除不会取消订阅，也不会删除笔记。新版客户端在付费正文显示期间维持短时阅读租约（约 90 秒，约 30 秒心跳）；关闭最后阅读窗口、退到后台、睡眠或退出时尽力停止，崩溃或断网后租约到期自动释放。切换设备时可选择结束某台正在阅读的设备；新设备须待目标停止或租约到期后再显示正文。旧版 Build 18/105/106 没有心跳，服务器不能对其严格执行 3 台；旧会话继续兼容，已下载或已解密的正文无法因并发限制收回。Build 19/107 及以后执行上述并发限制。

隐私与数据

本应用不投放广告，不接入第三方分析或追踪 SDK，不进行跨应用或跨网站追踪。订阅核验、设备登记、加密正文授权、在线检索和应用内反馈的处理范围与保存期限，详见隐私政策。
