全球法律汇编 — 隐私政策

生效日期：2026年10月26日 适用范围：全球法律汇编 Mac、iPhone 与 iPad 应用。个人内容默认保存在本机。 版本范围：本政策自 2026-10-26 起适用于 macOS 1.0 Build 19 及以后、iOS/iPadOS 1.20.3 Build 107 及以后。旧版本（包括 macOS Build 18、iOS/iPadOS Build 105/106）可能仍显示旧的启动协议页、学习功能入口或旧设备规则；其本机已有笔记、收藏和旧存档不会因升级被删除。新版行为以本政策为准。

一、处理范围概览

本应用是本地法律资料阅读、检索与笔记工具，不投放广告，不接入第三方分析或追踪 SDK，不进行跨应用或跨网站追踪。开发者不运营保存你笔记的服务器，也不会通过应用收集你的笔记内容。

Mac 版将笔记、摘录、批注、高亮、收藏、阅读位置、检索历史和本机界面偏好保存在你的 Mac 上。Build 19/107 及以后已移除学习中心、错题本、练习统计、思维导图和图谱入口，不再新增或展示这些功能的数据。旧版本保存在本机或 iCloud 的相关存档字段仍可能保留，用于兼容和取回既有内容；新版本不会主动删除这些旧字段，也不会把它们用于新功能或广告。Mac 版不会在启动时要求点击同意协议；协议和隐私政策可从应用菜单随时查看。本机可能保留历史协议阅读记录，仅用于显示状态，不阻断法库、搜索、笔记或设置。

iPhone 与 iPad 版将笔记、对照笔记、批注、高亮、收藏与置顶、书签、已读标记和阅读记录保存在本机；在登录 iCloud 并允许本应用使用 iCloud 时，上述阅读与笔记记录还会通过 Apple 的 iCloud 键值存储在你的 Apple 账户内同步，具体见第五节。检索历史、引注记录、协议同意状态和应用偏好仅保存在本机。旧版本保存的薄弱条文或练习统计不再新增，可能仍留在原存储中。

当前版本不提供应用内账户或“通过 Apple 登录”入口；旧版本若在本机留下过 Apple 返回的用户标识，新版本不会读取或上传。iCloud 同步与 Apple 账户登录分别管理，登录系统 iCloud 不会自动开启任何针对开发者的数据传输。

二、用途与权限

上述本机信息用于保存你的阅读与笔记内容、恢复阅读进度、执行本地搜索和展示笔记与收藏关系。应用只访问自身沙盒内的数据，以及你通过系统选择器主动选取的导入文件或导出位置；不要求访问通讯录、照片、摄像头、麦克风或精确位置。

Mac 版导入文件用于恢复你选择的完整笔记存档，导入时会在应用容器内保留原始存档副本。导出文件保存在你选择的位置，是否分享由你决定。iPhone 与 iPad 版的复制、分享与导出同样只处理你主动选择的内容，并通过系统分享面板完成。

朗读使用 Apple 系统提供的语音合成功能，声音资源和系统侧处理遵循 Apple 的相关设置与政策，不经过开发者服务器。

四、保存、删除与备份

Mac 版本地内容持续保存至你删除或移除相应文件。删除笔记后，可在回收站恢复；清空回收站中的对应内容后不再从应用界面恢复。检索历史可在搜索界面清除。导出备份和导入原始副本独立于当前笔记，删除笔记不会同时删除这些备份。通过系统管理应用存储时，请一并处理不再需要的备份；移除应用程序本身不一定清除系统保留的容器数据。你可以使用“导出完整笔记备份”保存本地数据；请妥善保管导出文件，应用不会替你加密你选择的备份文件。

iPhone 与 iPad 版删除笔记、收藏、书签或高亮后，本机记录会立即更新；在 iCloud 可用时，删除会通过 iCloud 键值同步反映到同一 Apple 账户的其他设备。删除应用会移除本机数据，但不必然删除已同步到 iCloud 的学习记录；该云端副本由 Apple 的 iCloud 服务保存和管理，开发者无法代为查看或删除。删除前请自行保存仍需要的内容。

本应用不承诺 iCloud 是永久备份。网络、设备、账户状态及 Apple 服务都可能影响同步与恢复，重要内容请另行备份。

Mac 版：同步默认关闭；只有你在应用中明确开启，应用才使用你当前 Apple 账户的 CloudKit 私有空间。同步内容包括笔记、摘录、批注、回收站、收藏、高亮，以及按“同步阅读进度”开关选择同步的上次阅读位置（该开关默认开启），以及用于同步和保留冲突的版本信息。旧版本可能已同步过学习集或导图存档字段，新版本不再新增这些内容，但不会自动删除云端旧副本。不上传法律数据库、检索历史、已读标记或本机界面偏好。开发者不经营保存你笔记的服务器，也不通过应用接收这些笔记。Apple 的 iCloud 服务按其隐私政策处理相关账户、存储和服务信息。

关闭 Mac 版同步会停止后续操作并保留本机内容，不会自动清除已上传的云端副本。同步前的本机备份独立保留；冲突可能保留多个版本，删除当前笔记不一定立即清除历史副本。可通过 Apple 提供的 iCloud 存储管理查看或管理应用数据；操作前应备份并暂停其他设备同步，避免尚未同步的设备再次上传。在回收站永久删除笔记时，会在后续同步中传播该记录的删除；这不等同于清除历史备份或一键清空整个 iCloud 应用空间。账户变化时暂停同步，不会自动把原账户工作区发送到新账户。

iPhone 与 iPad 版：当设备登录 iCloud 且允许本应用使用 iCloud 时，收藏、书签、笔记与对照笔记、高亮、已读标记和阅读记录会通过 Apple 的 iCloud 键值存储在同一个 Apple 账户内同步，以便你在自己的设备间恢复这些阅读与笔记记录。该同步由 Apple 提供，开发者不运营相应存储，也无法读取其中的内容。未登录 iCloud、关闭本应用的 iCloud 权限或系统无法使用 iCloud 时，这些记录只保存在本机；应用不会因此把内容发送给开发者。在同一台设备上切换 Apple 账户后，本机已经保存的学习记录仍会保留并继续显示；之后的变更可能同步到系统当前使用的 iCloud 账户。应用不保证不同账户之间的记录相互隔离，也不会自动把原账户的内容迁移到新账户。切换账户前，请先备份或清理本机记录，并在系统设置中管理 iCloud 账户与数据。停止使用 iCloud 或删除应用不必然清除 iCloud 中已有的键值记录；如需清理云端数据，请通过 Apple 提供的 iCloud 管理方式处理。

Build 19/107 及以后已移除学习中心、错题本、练习统计、思维导图和图谱入口，因此不再新增或更新这些功能的数据。旧版本已保存在本机或 iCloud 的相关存档字段不会被新版本主动删除，但也不再展示或用于新功能；如需清理，请先导出仍需要的内容，再按应用或系统存储管理方式处理。

六、订阅、加密法库与在线检索

译文数据库使用 Apple 自动续订年度订阅。购买、试用资格、扣费与取消由 Apple 处理，应用通过 StoreKit 读取和校验商品信息与交易权益，用于访问内容及恢复购买。应用不读取你的银行卡资料。国内法库及个人笔记不以订阅为使用条件。

访问付费域外法条、检查连接、管理授权设备及在线全文检索时，应用通过 HTTPS 向开发者的 api.globlelawcompilation.cn 服务发送 Apple 签名交易凭据，服务向 Apple 核验有效权益；正式和沙盒环境隔离。原始交易凭据及交易正文不写入日志或业务数据库。服务按有效订阅的原始交易标识派生不可直接显示 Apple 账号的订阅标识，用于关联授权设备，不据此获取你的姓名、邮箱或银行卡。

为防止授权请求重放并防止自动批量抓取，服务器保存订阅派生标识、应用生成的设备公钥及其摘要、设备类别（仅作显示）、最近使用时间，以及短期挑战、防重放和请求频率计数。设备登记不设数量或类别上限；电脑、iPad 或 iPhone 仅作显示和管理，不读取硬件序列号、设备名称或广告标识，也不据此识别个人。设备公钥不包含硬件序列号、设备名称或广告标识。连续 30 天未使用的登记可能在后续清理中移除，移除后可凭有效订阅重新登记；旧版界面可能仍显示旧设备规则，服务器已不再按台数限制。短期挑战约 30 秒、防重放约 90 秒、请求频率计数约 3 分钟（按固定分钟桶保存，旧桶在下一次请求时清理），计数只含订阅派生标识、请求类别（整法授权与下载／检索／阅读会话）、分钟桶和次数，不含正文、检索词、原始交易或 IP 地址。应用重装不一定清除系统钥匙串中的本机设备身份。若需处理设备登记或删除问题，请通过支持渠道联系，勿在公开页面发送交易凭据。

若你持有旧版月度、年度或 2／3／4 年期购买，应用只在恢复购买或打开付费内容时读取 Apple 交易并交由服务端核验当前状态。年度/月度旧订阅以 Apple 当前有效期为准；2／3／4 年期购买自 Apple 记录的购买时间起按相应年数计算（UTC，2月29日截止到2月28日）。过期、撤销、环境不符或无法验证的交易不授权。

打开一部付费法律时，应用会发送该法律所属法库版本、条文标识与绑定本机的设备证明，以取得最多 30 分钟的短时阅读授权。在该次授权有效期内，你可以连续阅读同一部法律，不必为每一条正文单独联网核验（较早版本可能按条文分别核验）；授权到期、应用返回前台或订阅状态变化后，应用可能重新验证。正文在本机仅短时驻留内存，下载缓存为密文；不支持付费正文离线阅读。加密不能防止用户对已经合法显示的内容截图或复制；你主动保存的摘录、笔记、剪贴板和导出文件可能包含明文，由你控制和保管，不会在订阅到期后自动收回。

在线检索付费域外正文时，服务器实时处理你输入的关键词以及法域、文件、条号等检索范围。这些查询可能敏感，请勿在检索框中输入不必要的个人或个案秘密；服务器不将检索词、结果正文或逐条阅读历史保存到业务数据库，也不把关键词用于广告或分析。国内本地检索与个人笔记检索不上传关键词。请求处理过程中网络基础设施会接触 IP 地址等连接信息，仅用于建立连接、安全和故障处理，不用于广告、画像或跨站追踪；订阅请求频率按订阅派生标识和请求类别统计，不按 IP 或地理区域限制。服务不接收你的个人笔记、批注、高亮、备份文件或旧导图存档。

七、应用内反馈

Mac、iPhone 与 iPad 版当前版本的“向作者反馈”会把反馈内容直接提交到开发者的 api.globlelawcompilation.cn 服务，再由服务器转发到作者邮箱（较早版本可能改为调用系统邮件应用）。提交内容包括你选择的反馈类型、相关法条或页面（选填）、反馈正文、回复方式（选填）、平台、应用版本与系统版本；如你在界面中关闭“附上应用与系统版本”，则不会附加版本信息。应用不会自动附加个人笔记、阅读记录、账号或设备标识。

服务器按 90 天规则保留反馈：仅在收到新的反馈提交或邮件投递任务时，清理创建时间早于 90 天的记录，因此不保证在第 90 天准时删除。反馈转发到作者邮箱后，邮箱中的副本由作者邮箱服务处理，不在应用服务器的清理范围内。为防止滥发，服务器按来源生成加盐散列并保存按小时汇总的提交计数，不保存明文 IP 地址，也不将反馈内容用于广告或分析。请勿在反馈中填写密码、交易凭据、他人隐私或不愿公开的资料。

公开的 GitHub Issues 支持页面属于公开讨论，内容对所有访问者可见，并受 GitHub 的服务条款与隐私政策约束；请勿提交笔记全文、身份信息、密码或其他私人资料。

涉及个人信息、交易凭据、账户或设备登记等不宜公开的问题，请使用应用内“向作者反馈”，或发送邮件至 minfazhixing@163.com；不要通过公开的 GitHub Issues 提交隐私请求。公开 Issues 仅适合不含个人信息的通用问题。

八、应用更新与法库更新

应用功能更新通过 App Store 分发。检查应用更新时，应用会向 Apple 的 iTunes 查询接口发送应用标识与你所在的国家或地区代码，并打开 App Store 完成更新；该过程由 Apple 处理。

法库更新独立于应用版本。应用通过 HTTPS 向 api.globlelawcompilation.cn 请求法库版本清单和更新包，校验完整性后在本机建库启用；该请求不上传你的笔记、收藏或 Apple 账户信息。iPhone 与 iPad 版可按设置仅在 Wi-Fi 下自动下载法库更新，蜂窝网络下只提示。
