本机资料

笔记、收藏、摘录、标签、引用、高亮、回收站、阅读位置、设置与搜索历史保存在本机，与法库分开。应用不向开发者上传这些个人资料；本地搜索不上传检索词。搜索历史可在搜索界面清除。Windows 当前没有跨设备笔记同步。

正式 Windows 客户端对本机个人资料进行应用层加密，密钥由 Windows 当前用户的安全存储保护。此保护不适用于浏览器预览或 Android。密码备份可跨设备恢复，忘记密码无法解密；JSON 导出包含明文个人资料，请妥善保管。导入、导出和保存反馈只处理你主动选择的文件。

删除笔记先进入回收站，永久删除后无法在应用内恢复。独立导出的备份不会同步删除。重置应用、删除应用数据或更换 Windows 用户，可能导致无法恢复原有资料，请事先做好密码备份。

账号与设备授权

账号服务开放后，注册及登录处理用户名与密码。服务器只保存加盐密码校验值，不保存密码明文。登录令牌只在客户端运行期内存中保留，服务器保存其摘要及最长 12 小时的有效期。关闭程序后需重新登录。

为校验域外正文访问权限，客户端生成应用设备签名密钥和公钥登记；不读取硬件序列号、设备名称或广告标识。设备私钥保存在本机，用于签署请求。独立账号服务使用独立的账号、购买记录和设备登记，不与 Apple 账号、订阅或 iCloud 记录合并。

你可在账号区域选择“注销账号”，输入当前密码确认。注销不可撤销，所有登录和域外访问授权失效；用户名、密码校验信息与未付款订单会被删除。为防止同一购买被重复认领，已付款记录和 Microsoft 权益绑定仅保留去除用户名与密码的必要记录。本机笔记、收藏和独立备份保留。注销不等于退款，重新注册不会自动继承购买；如有未到期购买，请先联系支持。

在线内容与购买

域外正文通过 HTTPS 连接 api.globlelawcompilation.cn。服务器处理账号授权、应用设备公钥、条文或法律标识、随机挑战及短时阅读会话；内容在授权后解密，仅短时保留在客户端内存。到期后需重新验证，受保护正文不支持离线阅读。应用未开放账号或购买时，不会显示付款成功或自动授予权益。

仅在你明确提交在线域外正文检索时，发送关键词和检索范围，不附带笔记或本机搜索历史。服务器关闭访问日志，不记录请求正文、密码、令牌或检索词。防滥用处理使用来源 IP 的摘要和短时计数；网络基础设施仍需处理 IP 地址以传输请求。

Microsoft Store 版购买由 Microsoft 处理，应用与开发者服务核验商品、SKU、购买标识、有效期限和账号绑定。开发者不接收你的银行卡资料或 Microsoft 密码。购买价格、期限与是否续费须在付款前展示，以商店确认页为准；商店身份或服务未就绪时不开放购买。购买、退款及 Microsoft 自身的数据处理适用其隐私声明及交易条款。

权限与第三方

应用不要求通讯录、照片、摄像头、麦克风或位置权限，不投放广告，不接入第三方分析或追踪 SDK。朗读仅选择系统本地语音。浏览器打开支持页面或邮件应用由你主动操作，并适用相应服务的政策。
