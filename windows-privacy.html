适用范围：全球法律汇编 Windows 客户端；Apple 平台适用独立的隐私政策。

本机资料

笔记、收藏、摘录、标签、引用、高亮、回收站、阅读位置、设置与搜索历史保存在本机，与法库分开。应用不向开发者上传这些个人资料；本地搜索不上传检索词。搜索历史可在搜索界面清除。Windows 当前没有跨设备笔记同步。

正式 Windows 客户端对本机个人资料进行应用层加密，密钥由 Windows 当前用户的安全存储保护。此保护不适用于浏览器预览或 Android。密码备份可跨设备恢复，忘记密码无法解密；JSON 导出包含明文个人资料，请妥善保管。导入、导出和保存反馈只处理你主动选择的文件。

删除笔记先进入回收站，永久删除后无法在应用内恢复。独立导出的备份不会同步删除。重置应用、删除应用数据或更换 Windows 用户，可能导致无法恢复原有资料，请事先做好密码备份。

Microsoft Store 与设备授权

Windows 版无需另行注册软件账号，不要求填写软件用户名或密码。购买和恢复通过 Microsoft Store 处理，应用与开发者不获取你的 Microsoft 账号密码或银行卡资料。Microsoft 自身的数据处理适用其隐私声明及交易条款。

域外正文访问服务处理应用生成的设备公钥、签名证明、商店权益凭据、商品和 SKU、购买标识、有效期限及必要授权记录，用于确认访问权、退款状态和防止滥用。不读取硬件序列号、设备名称或广告标识；不与 Apple 账号、订阅或 iCloud 记录合并。

设备签名私钥不可导出并保存在本机。服务端的一次性设备挑战有效期为 60 秒，设备会话最长 15 分钟；访问令牌仅在客户端运行期内存中保留，服务器保存其摘要。访问受保护正文时仍需最近五分钟内的微软权益核验，设备证明本身不会授予购买权益。

可在“访问权”中清除本机访问授权。此操作移除服务端本机设备授权及相关会话，使本机正文访问失效；本机笔记、收藏与独立备份保留。清除授权不会退款，也不删除微软商店的交易记录。之后可使用原微软商店账号恢复购买，无需另建软件账号。隐私或数据删除请求可通过下方邮箱联系。

在线内容与购买

域外正文通过 HTTPS 连接 api.globlelawcompilation.cn。服务器处理设备授权、条文或法律标识、随机挑战和短时阅读会话。正文经授权后解密，仅短时保留在客户端内存；受保护正文不支持离线阅读。服务或商店尚未配置完成时不开放购买，不会因本地时间或测试开关自动授予权益。

仅在你明确提交在线域外正文检索时，发送关键词和检索范围，不附带笔记或本机搜索历史。服务器关闭访问日志，不记录请求正文、密码、令牌或检索词。防滥用处理使用来源 IP 的摘要和短时计数；网络基础设施仍需处理 IP 地址以传输请求。

购买价格、期限及是否续费须在付款前展示，以 Microsoft Store 确认页为准。购买、退款和商店交易记录由 Microsoft 处理；应用和开发者服务向微软核验访问权。购买和恢复是否已开放，以应用实际状态为准。

权限与第三方

应用不要求通讯录、照片、摄像头、麦克风或位置权限，不投放广告，不接入第三方分析或追踪 SDK。朗读仅选择系统本地语音。浏览器打开支持页面或邮件应用由你主动操作，并适用相应服务的政策。

支持与数据请求

隐私、数据删除及购买问题请联系 minfazhixing@163.com。不要提供密码、完整笔记、完整数据库或个案秘密；可提供脱敏说明。Windows 中“保存反馈文件”只生成本机文件，不会自动发送。

公开支持页面用于不含隐私的问题。请勿公开提交身份信息、交易凭据或私人资料。为处理你的请求而主动提供的信息，仅用于该请求及必要的后续核实。

如数据处理范围发生实质变化，将更新本政策；需要新增权限或同意时，会在对应操作前说明。
